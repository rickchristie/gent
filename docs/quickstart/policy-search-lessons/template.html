A normal loop.
Two ways to find a policy.

Use Gent’s standard ReAct loop. Give it a policy tool that combines full-text search with vector search. Keep the loop, retrieval, and answer checks separate.

“An unused item arrived 10 days ago. Can I return it?”

Configure the standard pieces

react.NewAgent(model), toolchain.New(), and policy.NewPolicySearchTool(...) cover this path. You supply the model, an initialized embedder, and your policy documents.

Keep the two searches distinct

Policy search finds rules in documents. Tool search finds callable tools. You do not need SearchChain just to use hybrid policy retrieval.

Current API: gent.Loop and executor.NewRunner are the current names in this working copy. AgentLoop[Data] and executor.New[Data] remain compatibility APIs.

Normalize before you add

              

                Raw BM25 scores depend on the query. With a positive theoretical maximum, Gent
                divides by that maximum and caps the result at 1. It does not stretch the best
                observed hit to 1. Without that metadata, scores pass through.
              

            

            

              
Retrieve candidates before final top-K

              

                The policy helper requests up to 20 results per source, then fuses
                and returns 3 by default. Bleve can remove weak matches first.
                WithTopK changes the final count.
              

            

          

          

            What the browser experiment leaves out
            

              Bleve’s default confidence threshold is 0.001 of the theoretical maximum, with knee
              truncation enabled. FlatIndex scans chunk vectors and keeps each policy’s best chunk.
              The supplied cosine scores are illustrative, not probabilities or quality guarantees.
              Cosine can be negative; the fuser passes semantic scores through unchanged. The demo
              sorts tied scores by ID. The Go fuser does not define a tie order.
            

            

              The slider is a teaching control. PolicySearchTool has no weight setter.
              To change 40/60, compose the search indexes and expose them through your own tool.

    07 / RUN IT RELIABLY DESIGN CHOICES
    
          
    Use the right boundary
    for each check.
    
          
    
            Retrieval gives the model evidence. Your application still owns configuration, policy
            quality, resource lifetime, and the rules for any action.
          
    
          
    
            
            
          
    
          
    
            
    
              
    
              
    
              
            
    
            
    
          
    
          
    
            
    
              01
              
    
                
    Freeze configuration before shared use
    
                
    
                  Register tools, set result mode, and prepare policies before concurrent runs.
                  SearchIndex and Embedder implementations must support concurrent use. The helper
                  keeps policy pointers; do not change their content during a run.
                
    
              
    
            
    
            
    
              02
              
    
                
    Put limits on the execution context
    
                
    
                  SetLimits replaces the list. Start with
                  DefaultLimits() if you want to keep its error limits. Use
                  SCIterations.Self() for this context. An unfinished run stops after
                  the completed iteration reaches that limit. Most other limits stop when the value
                  exceeds the maximum.
                
    
              
    
            
    
            
    
              03
              
    
                
    Check both errors and the final reason
    
                
    
                  Handle the error from Execute, then inspect
                  ExecutionResult.TerminationReason. Tool errors can become
                  observations and allow a retry. Cancellation, limits, and recording errors can end
                  the run.
                
    
              
    
            
    
            
    
              04
              
    
                
    Keep the embedder alive for all searches
    
                
    
                  ONNX requires CGO, native libraries, and downloaded model files. With CGO
                  disabled, the built-in constructor returns an error. A custom
                  Embedder is an alternative. Always handle errors from
                  Close.
                
    
              
    
            
    
          
    
          
    
            When a result is missing or the wrong policy ranks first
            
    
              Check unique IDs and the indexed fields. Test an exact ID, a keyword query, and an
              intent query. Inspect source scores through a custom SearchIndex setup: the policy
              tool returns text and does not expose its private index. Compare expected policy IDs
              with full results. A high similarity score does not confirm that the policy applies.
            
    
          
    
          
    
            When you need custom weights, updates, or explicit index cleanup
            
    
              The convenience PolicySearchTool has no public index setter, weight setter, update
              method, or Close method. Compose BleveIndex, FlatIndex, and
              FusedIndex, then expose Search through your own Gent tool.
              Keep the Bleve handle so you can close it.
            
    
            
    
              FusedIndex calls its sources sequentially. Its update lock excludes searches during an
              update, but it does not roll back a partial backend failure. After a failed update,
              stop serving that index until a successful Swap restores the full
              document set.
            
    
          
    
          
    
            When you need policy compliance or recovery across workers
            
    
              Use AnswerValidator for answer checks and application code for
              authorization or mutations. A prompt is guidance; the default text termination accepts
              any non-empty answer. Policy search does not approve refunds.
            
    
            
    
              ExecutionContext owns append-only history and the active message selection. Durable
              recovery needs a Recorder and the checkpoint contract in docs/history.md.
              The standard runner and ReAct loop already use checkpoint barriers.
