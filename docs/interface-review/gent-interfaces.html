READ THE REFACTOR

Six boundaries worth discussing.

Coverage, comparison rules, and source provenance

Every named non-test interface in repository Go source is included. The additional capability checks are listed under Recovery. Eighteen concrete types supply context; this is not an inventory of every exported function, alias, or struct.

New and changed badges compare declarations with the same file and name at the recorded HEAD. Comments and method bodies are excluded. An unchanged signature can still have changed behavior. This is a snapshot: rebuild after editing Go source.

Tests, dependencies, hidden directories, and documentation generators are excluded. Source references are local checkout paths. No browser requests or provider calls are made.
